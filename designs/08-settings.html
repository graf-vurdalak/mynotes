Управление токенами для подключения ботов к вашему аккаунту

Как использовать токены?
Создайте токен, скопируйте его и используйте в Telegram-боте для авторизации. Бот будет отправлять данные на ваш сервер. Вы можете создать несколько токенов для разных устройств или инсталляций (dev, prod).

Важно о безопасности
  • Токены показываются только один раз при создании — сохраните их в надёжном месте
  • Не передавайте токены третьим лицам
  • Если токен скомпрометирован — немедленно отзовите его
  • Рекомендуется создавать отдельные токены для каждого устройства
