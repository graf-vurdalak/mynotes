# Ручная регрессия и доступность

Используйте этот список перед релизом и после изменений интерфейса. Для каждого
прогона укажите дату, версию приложения, браузер/устройство и результат; при
ошибке приложите URL, шаги воспроизведения и скриншот.

## Подготовка

- [ ] Запустить Docker Compose и проверить доступность приложения.
- [ ] Подготовить тестового пользователя без 2FA и отдельного пользователя с 2FA.
- [ ] Открыть DevTools: ошибки JavaScript, сетевые ошибки и ошибки API отсутствуют.

## Функциональная регрессия

- [ ] Войти с корректным паролем; с неверным паролем остаться на форме входа без раскрытия существования учётной записи.
- [ ] Для пользователя с 2FA пройти OTP challenge; проверить отклонение неверного кода и однократное использование резервного кода.
- [ ] Создать, открыть, изменить и удалить личное событие Бортжурнала; проверить сохранение дат и обязательных полей.
- [ ] Создать, изменить и завершить задачу Записной книжки; проверить статус и проект.
- [ ] Открыть настройки безопасности и список токенов; создать токен, убедиться в однократном показе секрета и отозвать его.
- [ ] Выйти и проверить, что защищённые страницы требуют повторной аутентификации.
- [ ] Проверить, что другой пользователь не может читать или изменять чужие объекты по прямому URL.

## Матрица браузеров и адаптивность

- [ ] Desktop: актуальные Chrome и Firefox, ширина 1280 px и 1440 px.
- [ ] iOS Safari: текущая поддерживаемая версия на реальном устройстве; проверить ширину 375–430 px.
- [ ] Android Chrome: текущая поддерживаемая версия на реальном устройстве; проверить ширину 360–430 px.
- [ ] На мобильных проверить вход/OTP, открытие меню, основные формы Бортжурнала и Записной книжки, модальные окна и прокрутку.
- [ ] Убедиться, что нет горизонтальной прокрутки, обрезанных кнопок/полей и перекрытия клавиатурой активного поля или ошибок формы.
- [ ] Проверить поворот экрана и повторное открытие меню/диалогов после изменения ориентации.

## Доступность

- [ ] Запустить автоматическую axe-core проверку E2E для страницы входа: нарушений WCAG 2.0/2.1 A/AA нет.
- [ ] Запустить axe DevTools/axe-core на Dashboard, формах события/задачи и настройках безопасности; каждое critical/serious нарушение устранить или зарегистрировать с обоснованием.
- [ ] Пройти формы клавиатурой без мыши: порядок Tab логичен, фокус видим, диалоги закрываются доступным способом.
- [ ] Проверить подписи полей и объявление ошибок, заголовки страниц и альтернативный текст значимых изображений.
- [ ] На мобильном проверить увеличение текста и системный размер шрифта без потери содержимого/функций.
